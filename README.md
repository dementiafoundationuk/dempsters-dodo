# Dempster's DoDo

A real Next.js MVP for Dempster's DoDo — a practical AI troubleshooting companion for caravan and motorhome toilets, water, waste and campsite plumbing problems.

## Run

```bash
npm install
cp .env.example .env.local
# add OPENAI_API_KEY to .env.local
npm run dev
```

## What is working

- Marketing homepage
- Diagnostic desk
- Text troubleshooting
- Photo upload to the diagnostic brain
- Safety-first system instructions
- Knowledge areas page
- Early-access page
